# Ảnh demo cho prompt

Upload ảnh `.jpeg` vào ngay thư mục này. Webclip tự tìm tên ảnh từ **tên tệp prompt gốc**: bỏ `.txt`, đổi khoảng trắng thành `_`, giữ nguyên các ký tự khác, rồi thêm `.jpeg`.

| Tệp prompt | Ảnh tương ứng trong Demo |
| --- | --- |
| `Intimate Couple.txt` | `Intimate_Couple.jpeg` |
| `Intimate Couple Close-up.txt` | `Intimate_Couple_Close-up.jpeg` |
| `Sang trọng.txt` | `Sang_trọng.jpeg` |

Tên ảnh phân biệt chữ hoa/thường. Prompt ở thư mục nào cũng tìm ảnh tại `Demo/` gốc; các prompt có cùng tên tệp dùng chung ảnh demo. Sau khi upload/đổi ảnh, chờ GitHub Pages triển khai xong rồi mở lại trình xem. Ảnh được giữ nguyên nội dung, không xử lý hoặc nén lại.
